POWER & SAFETY

Power Distribution & Safety Notes

• Use a separate 5V 10A UBEC for servo power. Never power 17 servos from the Raspberry Pi 5V rail.

• Connect all grounds (Pi, PCA9685 boards, UBEC, L298N) to a common ground star point.

• Keep servo signal wires away from the ultrasonic echo lines to reduce PWM noise.

• Add a 1000µF electrolytic capacitor across the servo V+ / GND terminals to absorb current spikes.

• HC-SR04 echo outputs are 5V: use a 1kΩ / 2kΩ divider before connecting to Pi GPIO.

📖

Biped 17-DOF Operating Guide

Everything you need to power, calibrate, animate and control the biped humanoid.

1

Power & Boot

  • Connect the 5V 10A UBEC to both PCA9685 V+ terminals.
  • Connect the Pi, PCA9685 boards, L298N and UBEC to a common ground.
  • Boot the Pi and open http://localhost:2090 or https://biped.shobots.party.
  • The Shobots menu can start and stop the biped server remotely.
2

17-DOF Layout

  • Head: pan + tilt (2 servos).
  • Torso: waist yaw (1 servo).
  • Arms: shoulder pitch + roll + elbow (3 each).
  • Legs: hip yaw + hip pitch + knee + ankle (4 each).
  • 2 + 1 + 6 + 8 = 17 servos.
3

Servo Calibration

  • Open the Servo Calibration tab.
  • Use the trim slider for each of the 17 servos.
  • Start with all trims at 0° and adjust only one joint at a time.
  • Use the 3D preview and the test gait buttons to verify motion.
  • Trims are applied to live motion and to exported Python code.
4

Walking & Poses

  • Use the D-pad or WASD / arrow keys to walk, strafe and turn.
  • Switch between Walk, March, Turn and Run modes.
  • Click any preset pose to move all 17 joints instantly.
  • Enable obstacle avoidance in Settings to react to the 4 ultrasonic sensors.
5

Gemini AI & Voice

  • Add a Gemini API key in Settings or the AI panel.
  • Type a command, describe the scene, or activate the microphone.
  • Gemini can call biped_walk, biped_pose and biped_stop.
  • Show 5 fingers to start walking, 2 fingers to wave, 1 finger for guard mode.
6

Music, TTS & Export

  • Import MP3 files into static/audio/ and play them from the browser or local speaker.
  • Select a dance routine to sync the pose with the music.
  • Text-to-speech is available through /api/tts/speak.
  • The talking mouth robot sits on the stage front edge: its jaw follows L298 channel 1 and its neck follows channel 2 in sync with AI speech.
  • Use Export Python Code to download a ready-to-run 17-servo script.
7

Network & Shobots

  • Local server: http://localhost:2090.
  • Public URL: https://biped.shobots.party.
  • Shobots master menu: https://shobots.party.
  • Server file: /home/markirgang/biped/server.py.
8

Troubleshooting

  • No camera? Check /dev/video0 and the camera source selector.
  • Servos jitter? Use a dedicated UBEC and common ground.
  • Port busy? Restart from the Shobots menu or run lsof -i:2090.
  • Logs: server.log in the project folder.
